# Desafio - Formulário de Cadastro

## Como abrir
1. Extraia a pasta do arquivo ZIP.
2. Abra a pasta `desafio-formulario` no VS Code.
3. Abra `index.html` no navegador (ou use a extensão Live Server).

## Arquivos
- `index.html`: estrutura do formulário.
- `style.css`: aparência e layout responsivo.
- `script.js`: validações de telefone, e-mail, CPF e data de nascimento.

## Importante
Este é um modelo inicial feito a partir dos requisitos visíveis nas imagens do desafio. Para ficar igual ao Figma, ajuste o layout, os textos e os campos conforme o design oficial.
